<!-- ============ FUN FACT ============ -->
## 🎯 Fun Math Fact

> ✨ A **one-step generative model** is the dream:
> instead of taking thousands of steps along a learned ODE/SDE,
> we ask a single neural network to do the whole journey —
> from pure noise $z \sim \mathcal{N}(0, I)$ straight to a sample $x \sim p_{\text{data}}$.
>
> $$x = f_\theta(z), \quad z \sim \mathcal{N}(0, I)$$
>
> One forward pass. One beautiful map. 🚀
